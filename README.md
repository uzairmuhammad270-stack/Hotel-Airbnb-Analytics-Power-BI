# Hotel & Airbnb Analytics – Power BI

## Overview

A **Power BI analytics dashboard** developed to analyze Hotel and Airbnb booking data. The dataset was cleaned and transformed into a **Star Schema** with fact and dimension tables, followed by the creation of one-to-many relationships for efficient data modeling.

## Key KPIs

* **Total Revenue**
* **Total Bookings**
* **Average Booking Value**
* **Average Guest Rating**
* **Occupancy Rate**

## Project Work

* Cleaned and transformed the dataset
* Designed a **Star Schema** using fact and dimension tables
* Created **one-to-many relationships** between tables
* Developed interactive visuals and dashboards
* Designed a user-friendly dashboard for quick analysis and insights

## Tools

**Power BI | Power Query | Data Modeling | DAX | Star Schema | Data Visualization**

## Objective

To transform hotel and Airbnb booking data into an **interactive and easy-to-read Power BI dashboard** for analyzing revenue, bookings, guest ratings, booking value, and occupancy performance.
